About Me

My name is Kemal and I am a Software Developer from Turkiye.

As I have a great passion for game development, I work with various programming and scripting languages such as C#, C++, Python, and LUA; as well as different game engines including Unity, Unreal Engine, Godot, Source and Goldsource.

I released my first game Sullen: Light is Your Friend (Developed using Unity and C#) on IndieDB in 2014. Since then, I'm pouring my creativity on software and game development.

As a person who loves to learn, I'm always looking for ways to expand my knowledge and skills. I'm currently learning Web Development and Machine Learning to broaden my horizons.

I'm always open to new opportunities and collaborations. If you have a project in mind, feel free to contact me!

Take care!

My Unity Projects

Here are some of the Unity projects that I've worked on:

Sullen: Light is Your Friend

This is the first game I published. I originally published it in 2014 on IndieDB. Later on, I gave it a remaster and re-released it on Steam in 2017

It's a linear horror game that runs on Unity and C#.

Liquor Wars: Tekel Defence

This is a prototype project that I've developed in my free time. The client requested it as a tribute for someone, and allowed me to publish after giving him a basic working prototype. So, it will be available on app stores in a short while.

It's a casual arcade/infinite-scroller game, targeted for Android devices and made with Unity using C#.

You defend your liquor store from alkies, and you weaponise your merchandise in the process.

The Sixty Four

This is another work-in-progress project that I'm working on. It will run on both PC and mobile and will try to give an old-school pixel vibe.

This project is also a story-rich game which takes place in the year 2064, in a post-apocalyptic UK, mainly in the tunnels of the Tube. A rougelite-ish game with randomly generated dungeons, loot and enemies.

Not much is certain about this project yet, but I will share more information in the future.
